# Fall 2026 student data bundle

`QM47400_Fall2026_course_data.zip` is the single archive to post on Brightspace for students.
The zip itself is **gitignored** (the repo does not carry `.zip` files); this README and
`build_data_bundle.sh` are what is tracked, so the bundle can be rebuilt byte-for-byte at any time.

## What the bundle contains

| Path inside the zip | Source in this repo | Who needs it |
|---|---|---|
| `case_competition/train.csv`<br>`case_competition/test.csv`<br>`case_competition/sample_submission.csv` | `_course_case_competition/2026F/fall-2026-qm-47400-case-competition-bank-churn/` | The semester-long Case Competition and `nb18`. Kaggle's Data tab is the authoritative copy. |
| `notebook_datasets/us_employment.csv` | `notebooks/us_employment.csv` | `nb16` — but the notebook reads it from a raw GitHub URL, so this is an offline convenience only. |
| `notebook_datasets/california_housing.csv` | `notebooks/california_housing.csv` | `nb01`–`nb05`, `nb08`, `nb09`, `nb11`–`nb14`, `nb19` — but those load it through `fetch_california_housing()`, so again offline only. |
| `README.txt` | generated by the build script | Student-facing explanation of every file and how to upload to Colab. |

**Not included, deliberately:** the MedScreen breast-cancer case ships inside scikit-learn
(`load_breast_cancer`) and has no file to distribute.

## Rebuild

```bash
bash _data/2026F/build_data_bundle.sh
```

Run it again after replacing the competition CSVs (for example if Kaggle reissues the data). It
rebuilds from the tracked sources, so the bundle can never drift from what the notebooks use.
